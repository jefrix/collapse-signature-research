## Methodology Notes

- **Definition of “first self-indictment signal”**: Public literary, philosophical, official, or institutional disclosure that names structural failure as inherent rather than contingent, produced while the regime or institution is still operational.
- **Source Type**: Literary, Philosophical, Official report, Model evaluation disclosure, Internal memo, etc.
- **Classification**: State-sanctioned / Non-state / Ambiguous.
- **Register**: Reformist (seeks correction while preserving the system) / Terminal (registers the system as structurally compromised) / Mixed.
- **Corpus Limitation Flag**: Used when absence of sources prevents coding rather than indicating absence of the phenomenon.
- **Terminal sequence onset**: Point at which systemic disintegration becomes irreversible.
